> Static linter preventing mobile horizontal overflow and viewport leakage in frontend code.

Zero dependencies. Instant scan. Compatible with Tailwind CSS, plain CSS, React, Vue, Svelte, Astro, HTML, and Laravel Blade.

---

## The Problem

Layouts generated by AI coding assistants frequently introduce mobile horizontal scroll leakage on viewports (<360px) due to:
1. `w-screen` measuring `100vw`, which includes the desktop/webview scrollbar width and causes immediate horizontal scroll.
2. Unconstrained rigid widths like `w-[600px]` or `min-w-[400px]`.
3. Flex children with `truncate` lacking `min-w-0` (causing flex items to refuse shrinking).
4. Raw `<table>` or `<pre>` blocks without an `overflow-x-auto` wrapper.
5. Unclipped negative margins (`-mx-4`, `-mx-8`).

## Installation & Usage

### 1. Instant Scan via `npx`

```bash
npx zero-overflow scan src/
```

### 2. Local Project Dependency

```bash
npm install -D zero-overflow-ui
```

Add to `package.json`:

```json
{
  "scripts": {
    "lint:overflow": "zero-overflow scan src/"
  }
}
```

---

## Configuration (`.overflowrc.json`)

Customize scanner behavior with an optional `.overflowrc.json` in your project root:

```json
{
  "ignoreRules": ["negative-margin-leak"],
  "ignorePaths": ["legacy", "vendor"]
}
```

## Enforced Rules

| Rule ID | Severity | Description | Fix Recommendation |
|---|---|---|---|
| `viewport-width-leak` | **ERROR** | Detects `w-screen` causing horizontal scrollbar leaks | Replace with `w-full` |
| `fixed-width-overflow` | **ERROR** | Fixed width >= 360px without responsive constraint | Use `w-full max-w-[...]` or `md:w-[...]` |
| `flex-truncate-leak` | **WARNING** | `truncate` on flex item without `min-w-0` | Add `min-w-0` to flex child |
| `table-pre-unwrapped` | **WARNING** | Raw `<table>` or `<pre>` without scroll container | Wrap in `<div class="overflow-x-auto w-full">` |
| `negative-margin-leak` | **WARNING** | `-mx-*` negative margins on base mobile viewports | Add parent `overflow-hidden` or restrict to `md:` |
